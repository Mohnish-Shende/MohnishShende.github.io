Notion Google Cloud MCP

Privacy policy

This policy describes how the personal integration operated by Mohnish Shende uses Google OAuth authorization and Google Cloud data.

Last updated: 22 September 2026

1. Application purpose

Notion Google Cloud MCP is a personal integration that allows an authorized Notion workflow or agent to authenticate with Google and access Google Cloud functionality through Google’s Cloud CLI MCP service. It is operated by Mohnish Shende and is not affiliated with, endorsed by, sponsored by, or owned by Google or Notion.

2. Google OAuth and Google Cloud access

The integration requests this Google OAuth scope:

https://www.googleapis.com/auth/cloud-platform

This is a broad Google Cloud scope. The effective access remains limited by the permissions assigned to the authorizing Google account and by Google Cloud IAM. The integration uses the authorization to perform Google Cloud operations requested through the authorized workflow; granting the scope does not itself add Google Cloud permissions to the account.

3. Data accessed and how it is used

Depending on the operation requested and the account’s permissions, the integration may access Google Cloud project and resource information, configuration, command inputs, command results, errors, and related metadata. That information is used only to authenticate the user, execute or support user-authorized Google Cloud operations, and return relevant results to the authorized Notion workflow or agent. It is not used for advertising or user profiling.

4. Data storage and retention

This public website repository contains static informational pages; it does not document the integration’s runtime architecture, operational logging, or persistence configuration. A categorical claim that Google Cloud data is never stored, or a fixed retention period, therefore cannot be made from the documented information. Google Cloud data may be processed by the runtime components needed to carry out an authorized request. For questions about whether specific operator-controlled data exists or to request its deletion, contact the operator using the address below.

5. Data sharing

Google Cloud data is not sold or rented. Information may be processed by Google services and by the authorized Notion workflow as inherent parts of the requested integration. The available repository does not establish whether any additional runtime infrastructure providers process operational data, so this policy does not make an unsupported claim that no such provider is involved.

6. OAuth credentials and tokens

OAuth credentials and tokens are used to authenticate authorized requests to Google services and must be treated as sensitive credentials. They are not intended to be published or used for unrelated purposes. Their exact storage mechanism and lifetime are determined by the integration’s runtime and Google’s OAuth controls; those implementation details are not present in this static website repository and are not asserted here.

7. Revoking access

A user may revoke the integration’s access through the third-party access or connected-app controls in the relevant Google Account. The user may also remove or disable the authorization used by the Notion workflow. Revocation prevents further authorized access through the revoked credentials, subject to Google’s OAuth behavior. Revocation does not by itself establish that any previously retained data has been deleted; deletion questions or requests should be sent to the operator.

8. Contact

Questions, access concerns, or deletion requests concerning this integration may be sent to Mohnish Shende at mohnish@mohnish.ink.
